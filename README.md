## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte dos meus estudos em **Design Web**, com o objetivo de criar um site **simples, moderno e totalmente responsivo**. O foco principal foi aplicar conceitos de layout, tipografia, cores e adaptabilidade a diferentes tamanhos de tela, garantindo uma boa experiência ao usuário em dispositivos móveis, tablets e desktops.

## 🎯 Objetivos

- Praticar os fundamentos de HTML semântico e CSS moderno
- Aplicar conceitos de **design responsivo** (mobile-first)
- Trabalhar com layout baseado em **Flexbox** e/ou **CSS Grid**
- Desenvolver uma interface limpa, acessível e agradável
- Publicar o projeto online para portfólio

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica do conteúdo
- **CSS3** — estilização, layout e responsividade
- **[JavaScript]** *(se aplicável)* — interações simples
- **[Google Fonts / Font Awesome]** *(se aplicável)* — tipografia e ícones
- **[Git e GitHub]** — versionamento e hospedagem

## 📱 Responsividade

O site foi construído com abordagem **mobile-first** e utiliza:

- **Media Queries** para adaptar o layout a diferentes breakpoints
- Unidades relativas (`rem`, `%`, `vw`, `vh`) para flexibilidade
- Imagens fluidas com `max-width: 100%`
- Layout adaptável com **Flexbox/Grid**

### Breakpoints utilizados

| Dispositivo | Largura |
|-------------|---------|
| Mobile      | até 480px |
| Tablet      | 481px – 768px |
| Desktop     | 769px – 1024px |
| Telas grandes | acima de 1024px |
